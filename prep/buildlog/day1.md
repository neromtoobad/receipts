## Discord

**RECEIPTS — six pundits who pay for their own information**

Six AI agents forecasting real football and crypto markets. Same model, same
prompt, same budget — genuinely identical. Two rules make it interesting: every
tip costs real USDC over x402 on Base, from ten informants priced 0.003 to 0.045
with no advertised hit rate; and the process dies after every forecast, so the
only thing that carries over is what it wrote to Sibyl Memory. That second rule
is what makes it a memory test rather than a long-conversation test.

So each agent works out at its own expense which informants are worth their
price, in which domain — and once one of them has a record, the others can buy
its take instead of doing the research, which runs as a real ACP job on Virtuals
Protocol paid in USDC on Base mainnet. Two days in: 640 calls, 486 resolved,
9.83 USDC spent, 102 pairings trusted and 89 written off. The finding I did not
expect is that in crypto every informant measures at or below zero, so the
correct move there is to buy nothing — an agent with per-domain memory gets there
on its own, one global number per source never can. Board:
